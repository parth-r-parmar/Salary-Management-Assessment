# Workspace Rules for Antigravity Agent

1. Read and strictly follow the project rules and standards defined in [AGENTS.md](../AGENTS.md).
2. Adhere to Test-Driven Development (TDD) for all backend and frontend services.
3. Validate all inputs using Zod; disallow `any`.
4. Ensure currency separation in all statistical queries and UI representations.
5. Produce small, incremental Conventional Commits reflecting each development milestone.
6. Record architectural choices, alternatives considered, and trade-offs in `docs/thinking-process.md`.
